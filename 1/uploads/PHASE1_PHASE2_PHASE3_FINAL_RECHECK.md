## Conflict Found and Fixed

### Issue

Phase 3 previously had a semantic ambiguity: it checked that `demo_trade=true` while also exposing a field named `approved_for_live_orders`. That could be misread as Phase 3 being able to approve live order placement.

### Fix

Phase 3 now explicitly cannot approve live orders.

```text
Phase 3 can approve readiness for manual-live review only.
It cannot approve live order placement.
A future deployment-control module must handle any explicit demo_trade=false switch.
```
